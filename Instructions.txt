================================================================================
          AI Missing Person Recovery System (PathBack) - User Instructions
================================================================================

1. PREREQUISITES & ENVIRONMENT SETUP
--------------------------------------------------------------------------------
* Ensure Python 3.10+ (or Python 3.12) is installed on your system.
* (Optional) Open PowerShell as Administrator and run the following once if 
  script execution is restricted:
      Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope CurrentUser

* Install all required dependencies:
      pip install -r requirements.txt


2. RUNNING THE APPLICATIONS
--------------------------------------------------------------------------------

A. Desktop / Admin Portal:
   - Command:
         python -m streamlit run .\Home.py
   - Or run the PowerShell script:
         .\run_desktop_app.ps1
   - Default Port: http://localhost:8501
   - Features:
       * Admin authentication & role-based dashboard
       * Register new missing person cases with automatic 128-D SFace extraction
       * Browse, search, filter, and audit case resolutions (Active / Solved)
       * FAISS AI Vector Match Engine (Sub-millisecond similarity lookups)
       * Real-time CCTV Video Surveillance Scanner with MOG2 motion gating,
         IoU multi-object face tracking, and deduplicated sighting alerts

B. Mobile / Public Sighting Portal:
   - Command:
         python -m streamlit run .\mobile_app.py --server.port 8502
   - Or run the PowerShell script:
         .\run_mobile_app.ps1
   - Default Port: http://localhost:8502
   - Features:
       * Public sighting submission portal for citizens and field officers
       * Upload photos or live camera captures with GPS & location coordinates
       * Automated face detection & L2-normalized 128-D embedding extraction


3. DEFAULT CREDENTIALS (ADMIN PORTAL)
--------------------------------------------------------------------------------
* Username : admin
* Password : admin123
* Configured in: login_config.yml


4. AI MODELS & ARCHITECTURE
--------------------------------------------------------------------------------
* Models directory: models/
  - SFace Deep Metric Recognition Model (sface.onnx) - 128-D L2-normalized embeddings
  - YuNet Face Detector (yunet.onnx) with CUDA GPU / OpenCV CPU caching
  - FAISS Vector Index (biometric_index.faiss) with NumPy matrix fallback
  - OpenCV MOG2 Motion Gating & IoU Multi-Object Tracking
  - Haversine Geospatial Radius Query Engine
* Database: sqlite_database.db (SQLModel / SQLite with automated schema migrations)


5. DATABASE & VECTOR INDEXING
--------------------------------------------------------------------------------
* When new cases are added, the FAISS biometric index dynamically updates.
* To manually build or refresh the offline FAISS vector index:
      python pages/helper/train_model.py
* To reset or reinitialize the database, you can back up or delete sqlite_database.db;
  the system will automatically recreate tables and apply migrations on startup.
